# Deep Learning Classification of ECG Arrhythmias

## Project Description

This project aims to apply deep learning techniques to automatically classify cardiac arrhythmias from electrocardiogram (ECG) signals. ECG signals record the electrical activity of the heart and contain patterns that can indicate abnormal heart rhythms such as atrial fibrillation or premature ventricular contractions. Accurate automated classification of ECG signals can support clinicians in identifying cardiovascular abnormalities more quickly and efficiently.

The dataset used for this project will be the MIT-BIH Arrhythmia Database, a publicly available dataset that contains annotated ECG recordings from multiple patients. Each heartbeat in the dataset is labeled with its corresponding rhythm type, making it suitable for supervised machine learning approaches.

The primary goal of this project is to train neural networks that can classify ECG heartbeats into different categories based on their signal patterns. We will experiment with multiple neural network architectures, including a fully connected neural network and a convolutional neural network (CNN) designed for time-series signal analysis. In addition, we will evaluate the impact of several hyperparameters such as learning rate, batch size, number of layers, and dropout rate by testing multiple parameter combinations.

Model performance will be evaluated using separate training and testing datasets. Evaluation metrics will include accuracy, precision, recall, and confusion matrices in order to compare model performance across architectures and parameter configurations.
